# 实验四：RLCD 校准决策（方案A/B）——独立文档

> 配方来源：Jev/RLCD 学习会话（sess_e8d9c5ac）。RLCD = 在 GRPO 的奖励中加入
> proper scoring rule（Brier）逼出概率校准。与 RLVR 的区别：r = r_correct + r_cal。
> 本文档独立于《实验小结.md》（那是 exp1-3 三联实验的记录）。

## 一、任务定义

**分类决策**：给定影评文本，从 5 个情感候选中选一个（SetFit/sst5，
train 8544 / validation 1101 / test 2210，均在本地缓存）。
候选有限 + gold 可验证——满足 RLCD 配方的硬性前提。

数据四字段映射：
```
state/question → 模板化影评分类指令（含 5 个候选）
candidates     → 0:very negative ... 4:very positive
gold           → 真实标签（0-4）
```
Prompt 停在 "Answer:"，completion 期望单 token（编号）。

## 二、方案B（已跑完）：r_cal 按采样动作计分

- 奖励：r = 0.5·r_correct + 0.5·r_cal_action；G=16, temp 1.0, 300 步，2 分钟
- 结果（exp4_rlcd_G16_v2）：accuracy 0.356 → 中段 0.463 → 尾部回落 0.36；
  零方差组 33~45%；有梯度步 61%；completion 4-5 token
- **结论**：管线全通、GRPO 能学分类决策（+0.26 vs 随机 0.20）；
  但单 token 拿不到分布 p → r_cal 与 r_correct 同信号 → 无校准锚，尾部震荡
  ——**校准必须走方案A**

## 三、方案A（本篇主体）：Brier 进 loss 的 trainer 覆写

### 设计
```python
class CalibratedGRPOTrainer(GRPOTrainer):
    def compute_loss(self, model, inputs, ...):
        grpo_loss = super().compute_loss(...)          # 标准 GRPO 项
        brier = self._brier_loss(model, inputs)        # 可微辅助项
        return grpo_loss + self.lambda_cal * brier
```
- Brier：对 completion 首个数字 token 位置，取候选 logits（"0"-"4" 与 " 0"-" 4"
  两个变体共 10 个 token id），softmax 后两两合并成 5 维分布 p；
  多类 Brier = Σ_k (p_k − y_k)²，y 为 gold 的 one-hot
- reward 只留 r_correct（校准信号不进 reward，彻底绕开"组内常量被消"问题）
- λ（lambda_cal）默认 0.5

### 验证纪律（来自配方）
1. validation 调参（accuracy + ECE）
2. test 只在最终用一次
3. 工具：torchmetrics.CalibrationError / sklearn

## 四、结果（2026-10-04）

### 方案A 运行（exp5_rlcd_calibrated_v2，wandb 项目 grpo-rlcd）
- 训练 300 步仅 2 分 51 秒；**有梯度步 300/300 = 100%**（Brier 不依赖组内方差，
  方案B 的信号缺陷被修复）
- 训练中 r_correct 在 0.28~0.37 震荡（GRPO 侧），熵 0.28→0.38 温和上升

### 双模型对照评估（sst5 validation 1101 题，eval_exp5.py）

| 指标 | base Qwen3-0.6B | exp5_calibrated | 变化 |
|------|-----------------|-----------------|------|
| accuracy | 0.326 | **0.402** | **+7.6pt** |
| **ECE(10bin)** | **0.466** | **0.125** | **降低 73%** |
| 平均置信度 | 0.792（严重过自信）| 0.524（贴近真实 0.40）| 校准成功 |

**可靠性图（bin: 置信度 vs 实际正确率）**：
- base：报 0.955 置信的 407 个样本实际只有 0.459 正确——**过自信近一倍**，
  典型的 CE 训练病症（那个会话理论的核心论点）
- exp5：报 0.35→实际 0.32、报 0.45→实际 0.37、报 0.55→实际 0.46、报 0.65→
  实际 0.47——置信度与正确率的差距收窄到 0.03~0.18，分布中心从过度自信的
  0.9 bin 移到诚实的 0.3-0.6 bin

**结论：RLCD 双目标同时达成**——决策更准（+7.6pt）且概率可信（ECE ↓73%）。
这是 proper scoring rule（Brier）作为可微损失的直接效果：它惩罚"报高置信
但错"和"报低置信但对"两种失配，逼出诚实概率。

## 五、三个版本的完整对照

| | 方案B（exp4）| 方案A（exp5）|
|---|---|---|
| 校准信号 | r_cal 按动作计分（与 r_correct 同信号，无校准）| Brier 进 loss（独立可微梯度）|

| accuracy（val）| ~0.36（训练口径，尾部回落）| **0.402** |

## 七、λ 与 G 扫描（2026-10-04，validation 1101 题）

4 组并行（GPU 0/1，各约 3-5 分钟）+ 已有 λ=0.5 基准：

| 配置 | accuracy | ECE | mean_conf |
|------|----------|-----|-----------|
| base（无训练）| 0.326 | 0.466 | 0.792 |
| **λ=0.25**, G=16 | 0.387 | 0.131 | 0.518 |
| **λ=0.5**, G=16（基准）| 0.402 | **0.125** | 0.524 |
| **λ=1.0**, G=16 | 0.402 | 0.128 | 0.529 |
| λ=0.5, **G=8**（补测）| **0.415** | 0.134 | 0.544 |
| λ=0.5, **G=32** | 0.395 | 0.144 | 0.539 |
| λ=0.5, **G=64** | 0.403 | 0.133 | 0.536 |

**结论**：
1. **λ 扫描**：0.25 略差（校准压力不足），0.5 与 1.0 打平（差异 <0.003，
   在运行噪声内）——**λ=0.5 即甜点**，配方默认值合适
2. **G 扫描（含补测 G=8）**：**G=8 的 accuracy 全场最高（0.415）**——分类任务
   组内多样性富足（zero_std 仅 0.10~0.25），小 G 完全够用且每步覆盖更多题目
   （G=8 时 2 道/步 vs G=16 的 1 道），多样性红利反超方差收益；ECE 0.134 与
   G=16 的 0.125 同水平（噪声内）。**G=8-16 都是合理选择；配方推荐的 32-64
   是为低多样性任务（如 MBPP）准备的，此处无收益**——与 exp2 的 k=8 最优
   汇成同一条定律：G 的最优值由任务的方差饥饿程度决定
3. 所有 RLCD 配置均远胜 base（acc +6~9pt，ECE ↓70%+），方案A 的效果稳健

方法论注：扫描在 validation 上做（纪律），test（2210 题）仍封存未动。

## 八、FPB 金融决策验证：+44.5pt / ECE ↓59%（2026-10-05）

数据：FinanceInc/auditor_sentiment（FPB allagree，标注者全票同意）
train 3577（尾部切 300 为 val）/ **test 969（官方测试集，一次性使用）**，
3 类：0=negative 1=neutral 2=positive。

训练：FPB-GRPO-RLCD-E1（wandb 项目 grpo-rlcd）——CalibratedGRPOTrainer
（Brier 进 loss，num_classes=3 参数化），G=8/batch 16/temp 1.0/lr 2e-6，
1688 步 ≈ 1 epoch，15 分钟。

### 双模型对照（test 969，一次性）

| 指标 | base zero-shot | **GRPO+RLCD** | 变化 |
|------|----------------|---------------|------|
| accuracy | 0.3065 | **0.7513** | **+44.5pt** |
| ECE(10bin) | 0.4197 | **0.1702** | **↓59%** |
| mean_conf | 0.726（过自信）| 0.918 | 置信度大幅上调且准确率同步上调 |

**三个要点**：
1. **clean 标签 + 可验证 + RLCD = 训练效果爆发**：zero-shot 基线远低于预期
   （0.31，预注册 0.55~0.70 落空——金融文本 3 分类对 0.6B 比预想难，neutral
   类尤甚），但这也意味着改进空间巨大：1 个 epoch 就 +44.5pt
2. **与 SST5 的对照构成"标签质量决定天花板与增益"的完整实证**：SST5（标签
   噪声）600→4000 条只能涨 5pt 且天花板 ~55%；FPB（标签干净）一个 epoch
   涨 44.5pt 直奔 75%+
3. **校准部分完成**：ECE ↓59%，但 mean_conf 0.918 vs acc 0.75 仍偏过自信——
   λ 或 epoch 可继续调（准确率暴涨期模型还没来得及校准到位）

### 级联调度评估：风险-覆盖曲线（2026-10-05，本次新增）

把两个模型的置信度当"调度信号"：按置信度降序排列 test 969 题，从高到低扫描，
统计"直答子集的准确率"随覆盖比例的变化（曲线图：`outputs/fpb_risk_coverage.png`，
数据：`outputs/fpb_risk_coverage.json`）：

| 直答覆盖率 | base 直答子集准确率 | GRPO+RLCD 直答子集准确率 |
|-----------|--------------------|--------------------------|
| 5% | 71.2% | **94.2%** |
| 21% | 54.6% | **94.6%**（最高）|
| 42% | 43.0% | **90.5%** |
| 58% | 39.6% | 85.2% |
| 79% | 34.1% | 80.0% |
| 100%（全直答）| 30.7% | 75.1% |

**业务数字**：
- 目标准确率 ≥85%：base 可直答 **0%**（永远达不到），GRPO+RLCD 可直答 **58%**
- 目标准确率 ≥90%：base 可直答 **0%**，GRPO+RLCD 可直答 **42%**
- base 唯一能看的区间是最自信的前 5%（71.2%），且迅速崩塌；RLCD 的曲线
  平滑且覆盖-准确率挂钩可靠

**解读**：这就是"校准的功能化"——RLCD 模型的置信度可以直接当调度信号用
（说 90% 就真 90%），使"小模型直答 + 大模型兜底"的级联系统成立；
base 的过自信使其置信度不可用于任何可靠性承诺。ECE 的 73% 下降在这里
转化为真金白银的推理成本节省。

## 九、数据规模验证——4000 条 × 1 epoch（2026-10-04）

`exp5_rlcd_4k`（λ=0.5/G=8/temp 1.0 不变，仅数据 600→4000 条、步数 300→2000，
完整 1 epoch，全程 37 分钟）。修复过程记录：数据集构建函数在改 n 参数时
被窄范围编辑误删 `.map()` 步骤（数据集丢失 prompt 列，第 0 步即崩）——
恢复后重跑。

| 指标 | base | 600 条（300 步）| **4000 条（2000 步）** |
|------|------|-----------------|------------------------|
| validation accuracy | 0.326 | 0.415 | **0.462** |
| ECE(10bin) | 0.466 | 0.134 | **0.090** |

**预注册预测命中**：预测 0.44~0.47 → 实测 0.462；ECE <0.15 → 实测 0.090。

**三点观察**：
1. **训练奖励曲线全程平坦**（0.38±0.03 无斜率）但 validation 大涨——每条
   数据只见一遍时，训练奖励反映题目难度噪声而非学习进度；**泛化提升只能
   靠 held-out 验证集测量**（这也是为什么 RL 训练必须留验证集）
2. **ECE 随数据量同步改善**（0.466→0.134→0.090）：更多样的训练样本让
   Brier 校准学得更稳——数据规模对校准的收益甚至比对 accuracy 更明显
3. **与 SFT 作业对照**（42M 模型全量 2 epochs SFT：SST5 test 47.0%）：
   本方案 4000 条（不到其一半数据、RL 方式、lr 1/50）已到 46.2%（validation，
   与其 test 口径近似）——**基本追平，且校准远优**（SFT 的 CE 训练必然
   过自信，其报告未测 ECE）

### 数据规模 × 效果 scaling 曲线（当前三点）

```
acc:   0.326 → 0.415 → 0.462   （边际收益递减但未饱和）
ECE:   0.466 → 0.134 → 0.090   （持续改善）
       base    600条   4000条
```
